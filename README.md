# API de gestión de usuarios

Proyecto de práctica que implementa una API REST para gestionar usuarios con **arquitectura hexagonal**. La separación entre dominio, casos de uso y adaptadores ayuda a reducir el acoplamiento y facilita las pruebas.

## Funcionalidades

- Crear usuarios.
- Consultar uno o todos los usuarios.
- Editar usuarios.
- Eliminar usuarios.

## Tecnologías

- Java 25
- Spring Boot y Spring MVC
- Spring Data JPA
- PostgreSQL
